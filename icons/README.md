# Your own move icons

StockCrab draws a built-in icon for every kind of move. To use your own, put files in this folder named after the kind of move:

`brilliant`, `great`, `best`, `excellent`, `good`, `inaccuracy`, `mistake`, `blunder`, `book`, `forced`, `miss`

with the extension `.svg`, `.png` or `.webp` (for example `brilliant.png`, `blunder.svg`). If a kind has no file, the built-in icon is drawn; if there are both an SVG and a PNG, the SVG is used.

Then press **Reload** next to the extension in `about:debugging` and refresh the chess.com / lichess page.

The icon sets of chess.com and lichess are their authors' artwork and are not included in this repository.
